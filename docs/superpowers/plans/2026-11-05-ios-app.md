# iOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native iPhone app that generates Master Password v3 site passwords identical to the Go CLI and shares the CLI's `config.json` through iCloud Drive.

**Architecture:** The algorithm lives in a Swift package `ios/MPWCore` (C target `CScrypt` for scrypt, Swift target `MPWCore` for the algorithm, identicon and config model) that mirrors the Go package `internal/mpw`. The SwiftUI app in `ios/MPW` holds the master key in a `Session` and the config in a `ConfigStore` backed by a coordinated, watched file in the app's iCloud container. Go and Swift tests read the same vector files in `internal/mpw/testdata/`.

**Tech Stack:** Go 1.22, Swift 6 (language mode 6), SwiftUI, Observation, CryptoKit, CommonCrypto, Swift Testing, XCTest (UI test only), XcodeGen, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-05-ios-app-design.md`

## Global Constraints

- iOS deployment target 17.0; iPhone only (`TARGETED_DEVICE_FAMILY = 1`); portrait.
- Swift tools version 6.0, `SWIFT_VERSION = 6.0`; MPWCore platforms `.iOS(.v17)`, `.macOS(.v14)`.
- No third-party dependencies, neither Swift nor Go.
- Bundle id `io.github.mistatwista.mpw`; iCloud container `iCloud.io.github.mistatwista.mpw`.
- The master password and master key are never written to disk, Keychain or logs.
- Session timeout in background: 120 seconds. Clipboard lifetime: 60 seconds, local only.
- `config.json` format is shared with the CLI: `FULL_NAME`, `sites[]` with `name`, `counter`, optional `type`. Unknown keys must survive a rewrite by the app.
- UI strings are English. Localization is out of scope.
- Commit messages: `go: …`, `ios: …`, `ci: …`, `docs: …` prefixes; end every message with the line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Work on branch `feature/ios-app`. Never push or force-push.
- Simulator for local runs: `iPhone 17 Pro` (any available iPhone simulator works; adjust `-destination` if it is missing).

## Deviations from the spec

The spec is updated together with this plan; these were found while prototyping every task's code:

- scrypt: instead of Colin Percival's reference code (its repository splits it over many internal headers), `CScrypt` is ~100 lines written from RFC 7914, using the RFC's Salsa20/8 reference code and PBKDF2-HMAC-SHA256 from CommonCrypto. Verified against the RFC 7914 vectors.
- `MasterKey` is a `final class` (not a struct) so it can zero its buffer in `deinit`.
- "Offer to save the name": a "Remember name" toggle on the unlock screen, shown only when the config has no `FULL_NAME`, on by default.

```go
	t.Helper()
```

```go
// Package config reads the optional mpw JSON config:
//
//	{
//	  "FULL_NAME": "Robert Lee Mitchell",
//	  "sites": [{"name": "github.com", "counter": 2, "type": "Long"}]
//	}
//
// The iOS app reads and writes the same file and keeps keys it does not know.
package config

import (
	"encoding/json"
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
)

type Site struct {
	Name    string `json:"name"`
	Counter uint32 `json:"counter"`
	// Type is a result type name such as "Long". Empty means the default.
	Type string `json:"type,omitempty"`
}

type Config struct {
	FullName string `json:"FULL_NAME"`
	Sites    []Site `json:"sites"`
}

// Site returns the settings stored for the named site.
func (c Config) Site(name string) (Site, bool) {
	for _, s := range c.Sites {
		if s.Name == name {
			return s, true
		}
	}
	return Site{}, false
}

// PathEnv names the environment variable with an explicit config path.
const PathEnv = "MPW_CONFIG"

// Path is $MPW_CONFIG when set, then $XDG_CONFIG_HOME/config.json when
// XDG_CONFIG_HOME is set, otherwise ~/.config/mpw/config.json.
func Path() string {
	if p := os.Getenv(PathEnv); p != "" {
		return p
	}
	if dir := os.Getenv("XDG_CONFIG_HOME"); dir != "" {
		return filepath.Join(dir, "config.json")
	}
	return filepath.Join(os.Getenv("HOME"), ".config", "mpw", "config.json")
}

// Load reads the config at path. A missing file yields an empty config.
func Load(path string) (Config, error) {
	b, err := os.ReadFile(path)
	if errors.Is(err, fs.ErrNotExist) {
		return Config{}, nil
	}
	if err != nil {
		return Config{}, err
	}

	var c Config
	if err := json.Unmarshal(b, &c); err != nil {
		return Config{}, fmt.Errorf("parse %s: %w", path, err)
	}
	return c, nil
}
```

```go
// parseFlags parses args (without the program name). Long and short forms
// of a flag share one variable, so whichever comes last wins.
func parseFlags(args []string, output io.Writer) (flags, error) {
	var (
		f          flags
		resultType string
	)

	fs := flag.NewFlagSet("mpw", flag.ContinueOnError)
	fs.SetOutput(output)

	fullNameHelp := fmt.Sprintf("full name of the user (overrides $%s and FULL_NAME in %s)", fullNameEnv, config.Path())
	fs.StringVar(&f.fullName, "full-name", "", fullNameHelp)
	fs.StringVar(&f.fullName, "u", "", "shorthand for -full-name")

	counterHelp := "site counter, increase it to rotate the password (overrides the site's counter in the config)"
	fs.UintVar(&f.counter, "counter", 1, counterHelp)
	fs.UintVar(&f.counter, "c", 1, "shorthand for -counter")

	var typeHelp strings.Builder
	typeHelp.WriteString("password template (overrides the site's type in the config):")
	for _, rt := range mpw.ResultTypes {
		fmt.Fprintf(&typeHelp, "\n%s, %s", rt.Abbr, rt.Type)
```

```c
// scrypt as specified in RFC 7914. Salsa20/8 core is the reference code from
// RFC 7914 section 3; PBKDF2-HMAC-SHA256 comes from CommonCrypto.

#include "mpw_scrypt.h"

#include <CommonCrypto/CommonCryptoError.h>
#include <CommonCrypto/CommonKeyDerivation.h>
#include <stdlib.h>
#include <string.h>

#define R(a, b) (((a) << (b)) | ((a) >> (32 - (b))))

static void salsa20_8(uint32_t B[16]) {
    uint32_t x[16];
    memcpy(x, B, sizeof(x));
    for (int i = 8; i > 0; i -= 2) {
        x[ 4] ^= R(x[ 0]+x[12], 7);  x[ 8] ^= R(x[ 4]+x[ 0], 9);
        x[12] ^= R(x[ 8]+x[ 4],13);  x[ 0] ^= R(x[12]+x[ 8],18);
        x[ 9] ^= R(x[ 5]+x[ 1], 7);  x[13] ^= R(x[ 9]+x[ 5], 9);
        x[ 1] ^= R(x[13]+x[ 9],13);  x[ 5] ^= R(x[ 1]+x[13],18);
        x[14] ^= R(x[10]+x[ 6], 7);  x[ 2] ^= R(x[14]+x[10], 9);
        x[ 6] ^= R(x[ 2]+x[14],13);  x[10] ^= R(x[ 6]+x[ 2],18);
        x[ 3] ^= R(x[15]+x[11], 7);  x[ 7] ^= R(x[ 3]+x[15], 9);
        x[11] ^= R(x[ 7]+x[ 3],13);  x[15] ^= R(x[11]+x[ 7],18);
        x[ 1] ^= R(x[ 0]+x[ 3], 7);  x[ 2] ^= R(x[ 1]+x[ 0], 9);
        x[ 3] ^= R(x[ 2]+x[ 1],13);  x[ 0] ^= R(x[ 3]+x[ 2],18);
        x[ 6] ^= R(x[ 5]+x[ 4], 7);  x[ 7] ^= R(x[ 6]+x[ 5], 9);
        x[ 4] ^= R(x[ 7]+x[ 6],13);  x[ 5] ^= R(x[ 4]+x[ 7],18);
        x[11] ^= R(x[10]+x[ 9], 7);  x[ 8] ^= R(x[11]+x[10], 9);
        x[ 9] ^= R(x[ 8]+x[11],13);  x[10] ^= R(x[ 9]+x[ 8],18);
        x[12] ^= R(x[15]+x[14], 7);  x[13] ^= R(x[12]+x[15], 9);
        x[14] ^= R(x[13]+x[12],13);  x[15] ^= R(x[14]+x[13],18);
    }
    for (int i = 0; i < 16; i++) B[i] += x[i];
}

static uint32_t le32dec(const uint8_t *p) {
    return (uint32_t)p[0] | ((uint32_t)p[1] << 8) | ((uint32_t)p[2] << 16) | ((uint32_t)p[3] << 24);
}

static void le32enc(uint8_t *p, uint32_t x) {
    p[0] = (uint8_t)x; p[1] = (uint8_t)(x >> 8); p[2] = (uint8_t)(x >> 16); p[3] = (uint8_t)(x >> 24);
}

// scryptBlockMix: B and Y are 32*r words each. Output replaces B.
static void block_mix(uint32_t *B, uint32_t *Y, uint32_t r) {
    uint32_t X[16];
    memcpy(X, &B[(2 * r - 1) * 16], sizeof(X));
    for (uint32_t i = 0; i < 2 * r; i++) {
        for (int k = 0; k < 16; k++) X[k] ^= B[i * 16 + k];
        salsa20_8(X);
        // Even blocks go to the first half, odd blocks to the second half.
        uint32_t dst = (i / 2 + (i & 1) * r) * 16;
        memcpy(&Y[dst], X, sizeof(X));
    }
    memcpy(B, Y, 32 * r * sizeof(uint32_t));
}

// scryptROMix on one 128*r byte block.
static void ro_mix(uint8_t *block, uint64_t n, uint32_t r, uint32_t *X, uint32_t *Y, uint32_t *V) {
    size_t words = 32 * (size_t)r;
    for (size_t k = 0; k < words; k++) X[k] = le32dec(&block[4 * k]);
    for (uint64_t i = 0; i < n; i++) {
        memcpy(&V[i * words], X, words * sizeof(uint32_t));
        block_mix(X, Y, r);
    }
    for (uint64_t i = 0; i < n; i++) {
        uint64_t j = X[(2 * r - 1) * 16] & (n - 1); // Integerify mod n
        for (size_t k = 0; k < words; k++) X[k] ^= V[j * words + k];
        block_mix(X, Y, r);
    }
    for (size_t k = 0; k < words; k++) le32enc(&block[4 * k], X[k]);
}

int mpw_scrypt(const uint8_t *password, size_t password_len,
               const uint8_t *salt, size_t salt_len,
               uint64_t n, uint32_t r, uint32_t p,
               uint8_t *dk, size_t dklen) {
    if (n < 2 || (n & (n - 1)) != 0 || r == 0 || p == 0) return -1;
    if ((uint64_t)r * p >= (1u << 30)) return -1;
    if (n > SIZE_MAX / 128 / r) return -1;

    size_t block_len = 128 * (size_t)r;
    uint8_t *B = malloc(block_len * p);
    uint32_t *XY = malloc(2 * block_len);
    uint32_t *V = malloc(block_len * (size_t)n);
    int rc = -1;
    if (B == NULL || XY == NULL || V == NULL) goto out;

    if (CCKeyDerivationPBKDF(kCCPBKDF2, (const char *)password, password_len, salt, salt_len,
                             kCCPRFHmacAlgSHA256, 1, B, block_len * p) != kCCSuccess) goto out;
    for (uint32_t i = 0; i < p; i++) {
        ro_mix(&B[i * block_len], n, r, XY, XY + 32 * r, V);
    }
    if (CCKeyDerivationPBKDF(kCCPBKDF2, (const char *)password, password_len, B, block_len * p,
                             kCCPRFHmacAlgSHA256, 1, dk, dklen) != kCCSuccess) goto out;
    rc = 0;

out:
    if (B) { memset_s(B, block_len * p, 0, block_len * p); free(B); }
    if (XY) { memset_s(XY, 2 * block_len, 0, 2 * block_len); free(XY); }
    if (V) { memset_s(V, block_len * (size_t)n, 0, block_len * (size_t)n); free(V); }
    return rc;
}
```

```swift
import CScrypt
import Foundation

public enum MPWError: Error, Equatable {
    /// scrypt failed: invalid parameters or out of memory.
    case keyDerivationFailed
}

/// The 64-byte master key derived from the full name and master password.
///
/// Phase 1 of the algorithm:
///
///     masterKey = SCRYPT( <master password>, scope . LEN(<name>) . <name>, N = 32768, r = 8, p = 2, 64 )
///
/// Held only in memory. The buffer is zeroed when the key is released; Swift may have made
/// copies, so this is hygiene, not a guarantee.
public final class MasterKey: @unchecked Sendable {
    // Immutable after init, so sharing across threads is safe.
    private let storage: UnsafeMutableBufferPointer<UInt8>

    /// Runs scrypt, which takes a noticeable fraction of a second: call it off the main actor.
    public init(fullName: String, masterPassword: String) throws {
        let salt = scoped(fullName)
        let password = Array(masterPassword.utf8)
        let buffer = UnsafeMutableBufferPointer<UInt8>.allocate(capacity: 64)
        let rc = mpw_scrypt(password, password.count, salt, salt.count, 32768, 8, 2, buffer.baseAddress, buffer.count)
        guard rc == 0 else {
            buffer.deallocate()
            throw MPWError.keyDerivationFailed
        }
        storage = buffer
    }

    deinit {
        _ = memset_s(storage.baseAddress, storage.count, 0, storage.count)
        storage.deallocate()
    }

    func withBytes<R>(_ body: (UnsafeBufferPointer<UInt8>) throws -> R) rethrows -> R {
        try body(UnsafeBufferPointer(storage))
    }
}

let scope = "com.lyndir.masterpassword"

/// `scope . UInt32BE(LEN(s)) . s`, where LEN counts UTF-8 bytes.
func scoped(_ s: String) -> [UInt8] {
    let bytes = Array(s.utf8)
    return Array(scope.utf8) + bigEndian(UInt32(bytes.count)) + bytes
}

func bigEndian(_ value: UInt32) -> [UInt8] {
    withUnsafeBytes(of: value.bigEndian) { Array($0) }
}
```

```swift
import CryptoKit
import Foundation

extension MasterKey {
    /// Phase 2: the site key.
    ///
    ///     siteKey = HMAC-SHA-256( <master key>, scope . LEN(<site name>) . <site name> . <counter> )
    public func siteKey(siteName: String, counter: UInt32) -> [UInt8] {
        let seed = scoped(siteName) + bigEndian(counter)
        return withBytes { key in
            Array(HMAC<SHA256>.authenticationCode(for: seed, using: SymmetricKey(data: key)))
        }
    }

    /// Phases 2 and 3: the password for a site.
    public func password(siteName: String, counter: UInt32, type: ResultType) -> String {
        sitePassword(siteKey: siteKey(siteName: siteName, counter: counter), type: type)
    }
}

/// Phase 3: render the site key with a template of the given type.
///
///     template = templates[ <site key>[0] % LEN( templates ) ]
///     passWord[i] = templateChars[ template[i] ][ <site key>[i+1] % LEN( passChars ) ]
public func sitePassword(siteKey: [UInt8], type: ResultType) -> String {
    let templates = type.templates
    let template = templates[Int(siteKey[0]) % templates.count]
    var out = [UInt8]()
    out.reserveCapacity(template.count)
    for (i, cls) in template.enumerated() {
        let chars = templateCharacters[cls]!
        out.append(chars[Int(siteKey[i + 1]) % chars.count])
    }
    return String(decoding: out, as: UTF8.self)
}
```

```swift
/// Any JSON value. Used to keep config keys this version does not know about.
public enum JSONValue: Equatable, Sendable, Codable {
    case string(String)
    case number(Double)
    case bool(Bool)
    case object([String: JSONValue])
    case array([JSONValue])
    case null

    public init(from decoder: Decoder) throws {
        let c = try decoder.singleValueContainer()
        if c.decodeNil() { self = .null }
        else if let v = try? c.decode(Bool.self) { self = .bool(v) }
        else if let v = try? c.decode(Double.self) { self = .number(v) }
        else if let v = try? c.decode(String.self) { self = .string(v) }
        else if let v = try? c.decode([JSONValue].self) { self = .array(v) }
        else { self = .object(try c.decode([String: JSONValue].self)) }
    }

    public func encode(to encoder: Encoder) throws {
        var c = encoder.singleValueContainer()
        switch self {
        case .string(let v): try c.encode(v)
        case .number(let v): try c.encode(v)
        case .bool(let v): try c.encode(v)
        case .object(let v): try c.encode(v)
        case .array(let v): try c.encode(v)
        case .null: try c.encodeNil()
        }
    }
}

/// Coding key for arbitrary strings, to read and write unknown keys.
struct AnyKey: CodingKey {
    var stringValue: String
    var intValue: Int? { nil }
    init(_ string: String) { stringValue = string }
    init?(stringValue: String) { self.stringValue = stringValue }
    init?(intValue: Int) { nil }
}
```

```swift
import Foundation

/// The config file shared with the Go CLI:
///
///     {
///       "FULL_NAME": "Robert Lee Mitchell",
///       "sites": [{"name": "github.com", "counter": 2, "type": "Long"}]
///     }
///
/// Keys this version does not know are kept in `extra` and written back unchanged.
public struct Config: Equatable, Sendable, Codable {
    public var fullName: String?
    public var sites: [Site]
    public var extra: [String: JSONValue]

    public init(fullName: String? = nil, sites: [Site] = [], extra: [String: JSONValue] = [:]) {
        self.fullName = fullName
        self.sites = sites
        self.extra = extra
    }

    public func site(named name: String) -> Site? {
        sites.first { $0.name == name }
    }

    static let fullNameKey = "FULL_NAME", sitesKey = "sites"

    public init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: AnyKey.self)
        fullName = try c.decodeIfPresent(String.self, forKey: AnyKey(Self.fullNameKey))
        sites = try c.decodeIfPresent([Site].self, forKey: AnyKey(Self.sitesKey)) ?? []
        extra = [:]
        for key in c.allKeys where key.stringValue != Self.fullNameKey && key.stringValue != Self.sitesKey {
            extra[key.stringValue] = try c.decode(JSONValue.self, forKey: key)
        }
    }

    public func encode(to encoder: Encoder) throws {
        var c = encoder.container(keyedBy: AnyKey.self)
        for (key, value) in extra { try c.encode(value, forKey: AnyKey(key)) }
        try c.encodeIfPresent(fullName, forKey: AnyKey(Self.fullNameKey))
        try c.encode(sites, forKey: AnyKey(Self.sitesKey))
    }

    /// Parses the file contents. Throws on invalid JSON.
    public static func decode(_ data: Data) throws -> Config {
        try JSONDecoder().decode(Config.self, from: data)
    }

    /// Pretty-printed with sorted keys, so diffs of the file stay readable.
    public func encoded() throws -> Data {
        let encoder = JSONEncoder()
        encoder.outputFormatting = [.prettyPrinted, .sortedKeys, .withoutEscapingSlashes]
        return try encoder.encode(self)
    }
}

public struct Site: Equatable, Sendable, Codable, Identifiable {
    public var name: String
    /// As stored. Missing or 0 means 1, like in the CLI.
    public var storedCounter: UInt32?
    /// As stored. Missing means Long; an unknown value makes the site unusable.
    public var storedType: String?
    public var extra: [String: JSONValue]

    public var id: String { name }

    public init(name: String, counter: UInt32 = 1, type: ResultType = .long) {
        self.name = name
        storedCounter = counter
        storedType = type.rawValue
        extra = [:]
    }

    public var counter: UInt32 {
        get { storedCounter.flatMap { $0 == 0 ? nil : $0 } ?? 1 }
        set { storedCounter = newValue }
    }

    /// nil when the stored type is not one of the known types.
    public var type: ResultType? {
        guard let storedType else { return .long }
        return ResultType(rawValue: storedType)
    }

    public mutating func setType(_ type: ResultType) { storedType = type.rawValue }

    static let nameKey = "name", counterKey = "counter", typeKey = "type"

    public init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: AnyKey.self)
        name = try c.decode(String.self, forKey: AnyKey(Self.nameKey))
        storedCounter = try c.decodeIfPresent(UInt32.self, forKey: AnyKey(Self.counterKey))
        storedType = try c.decodeIfPresent(String.self, forKey: AnyKey(Self.typeKey))
        extra = [:]
        let known: Set = [Self.nameKey, Self.counterKey, Self.typeKey]
        for key in c.allKeys where !known.contains(key.stringValue) {
            extra[key.stringValue] = try c.decode(JSONValue.self, forKey: key)
        }
    }

    public func encode(to encoder: Encoder) throws {
        var c = encoder.container(keyedBy: AnyKey.self)
        for (key, value) in extra { try c.encode(value, forKey: AnyKey(key)) }
        try c.encode(name, forKey: AnyKey(Self.nameKey))
        try c.encodeIfPresent(storedCounter, forKey: AnyKey(Self.counterKey))
        try c.encodeIfPresent(storedType, forKey: AnyKey(Self.typeKey))
    }
}
```

`ios/MPW/Session.swift`:

```swift
import Foundation
import MPWCore
import Observation

/// Holds the master key between unlock and lock and decides when to lock.
@MainActor @Observable
final class Session {
    /// How long the key survives while the app is in the background.
    static let backgroundTimeout: TimeInterval = 120

    private(set) var fullName: String?
    @ObservationIgnored private var key: MasterKey?
    @ObservationIgnored private var backgroundedAt: Date?
    @ObservationIgnored private let now: () -> Date

    init(now: @escaping () -> Date = Date.init) {
        self.now = now
    }

    var isUnlocked: Bool { fullName != nil }

    func unlock(fullName: String, key: MasterKey) {
        self.key = key
        self.fullName = fullName
        backgroundedAt = nil
    }

    func lock() {
        key = nil
        fullName = nil
        backgroundedAt = nil
    }

    func didEnterBackground() {
        if isUnlocked { backgroundedAt = now() }
    }

    func didBecomeActive() {
        if let since = backgroundedAt, now().timeIntervalSince(since) > Self.backgroundTimeout {
            lock()
        }
        backgroundedAt = nil
    }

    /// The device is about to lock: drop the key at once.
    func deviceWillLock() {
        lock()
    }

    /// nil when locked.
    func password(siteName: String, counter: UInt32, type: ResultType) -> String? {
        key?.password(siteName: siteName, counter: counter, type: type)
    }
}
```

```swift
import Foundation

/// Where config.json lives: the app's iCloud container when available, otherwise local.
struct ConfigLocation: Sendable {
    static let containerIdentifier = "iCloud.io.github.mistatwista.mpw"
    /// UI tests point the app at a temporary folder through this environment variable.
    static let overrideEnvironmentKey = "MPW_CONFIG_DIR"

    let fileURL: URL
    let isSynced: Bool

    static func local(directory: URL) -> ConfigLocation {
        ConfigLocation(fileURL: directory.appendingPathComponent("config.json"), isSynced: false)
    }

    /// Looking up the iCloud container can block, so this runs off the main actor.
    static func resolve() async -> ConfigLocation {
        if let dir = ProcessInfo.processInfo.environment[overrideEnvironmentKey] {
            return local(directory: URL(fileURLWithPath: dir))
        }
        let container = await Task.detached {
            FileManager.default.url(forUbiquityContainerIdentifier: containerIdentifier)
        }.value
        if let container {
            return ConfigLocation(
                fileURL: container.appendingPathComponent("Documents/config.json"),
                isSynced: true
            )
        }
        let documents = FileManager.default.urls(for: .documentDirectory, in: .userDomainMask)[0]
        return local(directory: documents)
    }
}
```

```swift
import Foundation
import MPWCore

/// Coordinated reads and writes of config.json, so iCloud and other processes see whole files.
enum ConfigFile {
    /// nil when the file does not exist.
    static func read(_ url: URL) throws -> Config? {
        var coordinationError: NSError?
        var result: Result<Config?, Error> = .success(nil)
        NSFileCoordinator(filePresenter: nil).coordinate(readingItemAt: url, options: [], error: &coordinationError) { url in
            result = Result {
                guard FileManager.default.fileExists(atPath: url.path) else { return nil }
                return try Config.decode(Data(contentsOf: url))
            }
        }
        if let coordinationError { throw coordinationError }
        return try result.get()
    }

    /// `presenter` is excluded from change notifications caused by this write.
    static func write(_ config: Config, to url: URL, presenter: NSFilePresenter?) throws {
        let data = try config.encoded()
        try FileManager.default.createDirectory(at: url.deletingLastPathComponent(), withIntermediateDirectories: true)
        var coordinationError: NSError?
        var result: Result<Void, Error> = .success(())
        NSFileCoordinator(filePresenter: presenter).coordinate(writingItemAt: url, options: .forReplacing, error: &coordinationError) { url in
            result = Result { try data.write(to: url, options: .atomic) }
        }
        if let coordinationError { throw coordinationError }
        try result.get()
    }
}

/// Calls `onChange` when another process (iCloud sync, the Files app) changes the file.
final class ConfigFilePresenter: NSObject, NSFilePresenter, @unchecked Sendable {
    let presentedItemURL: URL?
    let presentedItemOperationQueue = OperationQueue()
    private let onChange: @Sendable () -> Void

    init(url: URL, onChange: @escaping @Sendable () -> Void) {
        presentedItemURL = url
        self.onChange = onChange
        presentedItemOperationQueue.maxConcurrentOperationCount = 1
    }

    func presentedItemDidChange() { onChange() }
}
```

`ios/MPW/ConfigStore.swift`:

```swift
import Foundation
import MPWCore
import Observation

enum ConfigStoreError: LocalizedError, Equatable {
    case readOnly
    case emptyName
    case duplicateName(String)

    var errorDescription: String? {
        switch self {
        case .readOnly: "The config file is broken. Fix it before making changes."
        case .emptyName: "Site name must not be empty."
        case .duplicateName(let name): "\(name) is already in the list."
        }
    }
}

/// Owns config.json: loads it, saves edits, and reloads when it changes elsewhere.
@MainActor @Observable
final class ConfigStore {
    let location: ConfigLocation
    private(set) var config = Config()
    /// Set when the file exists but cannot be parsed. The store is read-only until it parses again.
    private(set) var loadError: String?
    @ObservationIgnored private var presenter: ConfigFilePresenter?

    init(location: ConfigLocation) {
        self.location = location
    }

    var isReadOnly: Bool { loadError != nil }

    /// Loads the file and starts watching it.
    func start() async {
        await reload()
        guard presenter == nil else { return }
        let presenter = ConfigFilePresenter(url: location.fileURL) { [weak self] in
            Task { @MainActor in await self?.reload() }
        }
        NSFileCoordinator.addFilePresenter(presenter)
        self.presenter = presenter
    }

    func stop() {
        if let presenter { NSFileCoordinator.removeFilePresenter(presenter) }
        presenter = nil
    }

    func reload() async {
        let url = location.fileURL
        let result = await Task.detached { Result { try ConfigFile.read(url) } }.value
        switch result {
        case .success(let loaded):
            config = loaded ?? Config()
            loadError = nil
        case .failure(let error):
            loadError = error.localizedDescription
        }
    }

    func setFullName(_ name: String) throws {
        try update { $0.fullName = name }
    }

    /// Adds `site`, or replaces the site called `originalName`.
    func save(_ site: Site, replacing originalName: String? = nil) throws {
        let name = site.name.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !name.isEmpty else { throw ConfigStoreError.emptyName }
        if name != originalName, config.site(named: name) != nil {
            throw ConfigStoreError.duplicateName(name)
        }
        var site = site
        site.name = name
        try update { config in
            if let originalName, let index = config.sites.firstIndex(where: { $0.name == originalName }) {
                config.sites[index] = site
            } else {
                config.sites.append(site)
            }
        }
    }

    func delete(siteNamed name: String) throws {
        try update { $0.sites.removeAll { $0.name == name } }
    }

    private func update(_ change: (inout Config) -> Void) throws {
        guard !isReadOnly else { throw ConfigStoreError.readOnly }
        var updated = config
        change(&updated)
        try ConfigFile.write(updated, to: location.fileURL, presenter: presenter)
        config = updated
    }
}
```

```swift
import MPWCore
import SwiftUI

struct UnlockView: View {
    let session: Session
    let store: ConfigStore

    @State private var fullName = ""
    @State private var masterPassword = ""
    @State private var rememberName = true
    @State private var isDeriving = false
    @State private var error: String?

    var body: some View {
        NavigationStack {
            Form {
                Section {
                    TextField("Full name", text: $fullName)
                        .textContentType(.name)
                        .autocorrectionDisabled()
                        .accessibilityIdentifier("fullName")
                    SecureField("Master password", text: $masterPassword)
                        .textContentType(.password)
                        .accessibilityIdentifier("masterPassword")
                        .onSubmit(unlock)
                    if store.config.fullName == nil && !store.isReadOnly {
                        Toggle("Remember name", isOn: $rememberName)
                    }
                } footer: {
                    if !fullName.isEmpty && !masterPassword.isEmpty {
                        HStack {
                            Spacer()
                            IdenticonView(identicon: Identicon(fullName: fullName, masterPassword: masterPassword))
                            Spacer()
                        }
                        .padding(.top)
                    }
                }
                Section {
                    Button(action: unlock) {
                        if isDeriving { ProgressView() } else { Text("Unlock") }
                    }
                    .disabled(fullName.isEmpty || masterPassword.isEmpty || isDeriving)
                    .accessibilityIdentifier("unlock")
                }
                if let error {
                    Section { Text(error).foregroundStyle(.red) }
                }
            }
            .navigationTitle("mpw")
            .onAppear { fullName = store.config.fullName ?? fullName }
        }
    }

    private func unlock() {
        guard !fullName.isEmpty, !masterPassword.isEmpty, !isDeriving else { return }
        let name = fullName, password = masterPassword
        isDeriving = true
        error = nil
        Task {
            defer { isDeriving = false }
            do {
                let key = try await Task.detached(priority: .userInitiated) {
                    try MasterKey(fullName: name, masterPassword: password)
                }.value
                if rememberName && store.config.fullName == nil && !store.isReadOnly {
                    try? store.setFullName(name)
                }
                masterPassword = ""
                session.unlock(fullName: name, key: key)
            } catch {
                self.error = "Could not derive the master key."
            }
        }
    }
}
```

```swift
import SwiftUI
import UIKit

/// Switches between unlock and the site list, and applies the session lock rules.
struct RootView: View {
    let session: Session
    let store: ConfigStore
    @Environment(\.scenePhase) private var scenePhase

    var body: some View {
        Group {
            if session.isUnlocked {
                SiteListView(session: session, store: store)
            } else {
                UnlockView(session: session, store: store)
            }
        }
        .overlay {
            // Hides passwords in the app switcher snapshot.
            if scenePhase != .active { PrivacyCover() }
        }
        .onChange(of: scenePhase) { _, phase in
            switch phase {
            case .background: session.didEnterBackground()
            case .active:
                session.didBecomeActive()
                Task { await store.reload() }
            default: break
            }
        }
        .onReceive(NotificationCenter.default.publisher(for: UIApplication.protectedDataWillBecomeUnavailableNotification)) { _ in
            session.deviceWillLock()
        }
    }
}

struct PrivacyCover: View {
    var body: some View {
        ZStack {
            Rectangle().fill(.background)
            Image(systemName: "lock.fill")
                .font(.largeTitle)
                .foregroundStyle(.secondary)
        }
        .ignoresSafeArea()
    }
}
```
